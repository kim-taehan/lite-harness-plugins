# 플러그인 패널 디자인 규칙

UI 테스트 [환경] 팝업 · 목록 · 상세 시안(2026-11-09 확정)에서 나온 규칙. 모든 화면이 이것을 따른다. 바꾸려면 이 파일을 먼저 고친다. 구현은 `plugins/ui-test/index.html` 하나의 `:root` 토큰 세트(라이트 · 다크)로 통일돼 있다.

## 방향
- 의도: 테스트를 돌려 놓고 결과를 기다리는 개발자. 화면마다 "하러 온 일" 하나가 주인공.
- 느낌: 실험 장비의 조용한 패널 — 차갑고 정확하게. 청회색 종이 + 먹색 글자. 색은 선택(강조)과 통과(초록) 두 가지만 크게 쓴다.
- 서명: 선택 타일 안의 작은 도판(창 없는/있는 브라우저, 결과서=표, 가이드=흐름). 글을 읽기 전에 무엇을 고르는지 보인다. 새 선택지에는 그 선택지를 그대로 그린 작은 그림을 붙인다. **목록 · 상세에는 장식 서명을 두지 않는다** — 눈금 띠 · 막대 · 점선 같은 장식 대신 굵기 · 명도 · 여백의 위계로 읽히게 한다.
- 깊이: 테두리는 투명도 낮은 선(`rgba`), 뜨는 것(팝업)만 겹겹의 약한 그림자. 둘을 섞지 않는다.

## 글자
- 시스템 글꼴(`-apple-system`, `Apple SD Gothic Neo`, `Noto Sans KR`), 모노는 `ui-monospace`. 외부 글꼴 금지.
- 비율 약 1.2: 11.5(머리글, 600, 자간 +.06em, ink-3) · 12.5(설명, ink-2) · 13(본문) · 14~14.5(질문/항목/카드 제목, 650) · 19(팝업 · 화면 · 시나리오 제목, 700, 자간 -.018em).
- `html` 에 `-webkit-font-smoothing: antialiased`.
- 위계는 크기 + 무게 + 명도 세 가지를 같이. 숫자는 `tabular-nums`. 제목 `text-wrap: balance`, 설명 `text-wrap: pretty`.

## 간격 · 모양
- 기본 단위 4px. 팝업 안쪽 여백 20, 섹션 사이 22, 같은 섹션의 그룹 사이 18, 질문과 타일 사이 8, 타일 사이 8.
- 반지름: 팝업 20 · 타일/주소창/카드 12 · 작은 도판 8 · 단추 8 · 안내 상자(카드 안) 8 · 칩 99. 안쪽 = 바깥 − 여백.
- 화면(패널) 안쪽 여백 16, 카드 사이 14, 카드 안쪽 14.
- 누르는 영역 최소 30px(밀집 단추) / 타일은 훨씬 크게. 눌릴 때 `scale(.97~.985)`, 전환 100~150ms ease-out(`cubic-bezier(.23,1,.32,1)`), `prefers-reduced-motion` 에서는 끈다.

## 컴포넌트 규격
- **선택 타일** (라디오): well 면 + 테두리 1px(rule) · 안에 도판(높이 58, sheet 면) · 아래에 이름(13.5/650)과 설명(12/ink-2) · 선택되면 probe-wash 면 + 1.5px probe 테두리 + 3px probe-wash 띠 + 오른쪽 체크 원(18px). 방향키로 이동, 고르면 바로 저장. 좁은 폭(≤470)에서는 도판 왼쪽 · 글 오른쪽 한 줄로.
- **주소창 줄**: well 면 · 왼쪽 상태 점(8px, pass + 3px wash) · 모노 글꼴 주소 · 오른쪽 보조 글(브라우저) · 맨 끝 [설정 열기 ↗](sheet 면 + rule-strong 테두리, probe 글자).
- **파일 줄**: rule 테두리 · 32px 아이콘 칸 · 모노 파일명 + 한 줄 설명 · 오른쪽 투명 단추(열기 · 다시 만들기).
- **바닥 줄**: well 면 + 위쪽 1px rule · 왼쪽 안내 · 오른쪽 "✓ 저장했습니다"(pass, 1.8초 뒤 사라짐). 저장/닫기 단추는 없다 — 선택은 즉시 저장.

- **카드** (묶음 · 시나리오 · 단계 · 이력): sheet 면 + `0 0 0 1px rule` · 반지름 12 · 안쪽 14. 머리는 이름(14.5/650) + 보조 글(12/ink-3), 머리 전체가 펼침 단추(`aria-expanded`)이고 오른쪽 단추만 따로 눌린다. 안쪽 구획(시나리오 줄 · 고르기 · 규칙)은 위쪽 1px rule, 파인 구획은 well 면.
- **카드 요약은 글 한 줄**: `[실패 n 칩] 성공 n · 안 돌림 n …… 규칙 a/b 다룸`. 실패가 있으면 빨간 칩 하나만 시선을 끈다. 실패 0 이고 모두 성공이면 초록 "모두 성공" 칩, 한 번도 안 돌렸으면 회색 글자 "아직 안 돌림". 규칙 수는 어림값이라 title 로 설명하고, 규칙이 없으면 칸을 숨긴다. 막대 · 눈금 · 점은 쓰지 않는다.
- **용어**: 성공 · 실패 · **안 돌림**(한 번도 안 돌렸거나 멈춘 것) · 수행 중 · 대기. "수행 전" · "그 밖" 은 쓰지 않는다.
- **수행 중**: `n/m` 큰 글 + `수행 — 이름 · 단계 k` + 가는 진행선(3px), 단추는 [멈추기]. 그 카드만 probe 링(1.5px + 4px wash), 나머지 카드는 투명도 .52. 깜박이는 연출 없음.
- **단추 종류**(높이 30, 반지름 8, `.btn`): 기본(sheet + rule-strong) · primary(probe 면 — 화면마다 하나, 하는 일) · tint(probe-wash — 행동 안내) · ghost(투명 — 새로 고침 · 목록) · danger(빨간 글자 + 옅은 테두리 — 삭제 진입) · solid-bad(빨간 면 — 확인 상자 안의 삭제만) · link(글자만, 최소 높이 28 — 줄 안의 [결과서] · [열기]). 눌림 `scale(.97)`, disabled 는 투명도 .45 + `not-allowed`.
- **확인 상자**(삭제): bad-wash 면 · 제목은 bad 글자 + 설명은 ink · 오른쪽 [취소] [삭제](solid-bad). 포커스는 안전한 쪽 [취소] 에 먼저 두고, Esc 는 취소, 취소하면 눌렀던 단추로 돌아간다. 카드 안에서는 가장자리 여백 12, 화면에 홀로 뜰 때는 `.free`(반지름 12 + bad 35% 테두리).
- **알림 한 줄**: sheet 면 + `--lift-sm`, 왼쪽 18px 원 표시(성공 ✓ / 안내 / 오류 ✕), 오른쪽 ✕. 성공은 8초 뒤 저절로 사라지고(아래 2px 선이 줄어든다), 오류(`role=alert`)는 닫을 때까지 남고 bad 글자. 다시 그려도 연출이 처음부터 돌지 않게 경과 시간만큼 건너뛴다.
- **시나리오 줄**: 최소 높이 48, 상태 점(8px; 실패만 3px wash) · 이름(13/550) · 아래에 종류 · 태그 칩 · 오른쪽 상태 칩 + ›. 태그: 코드 없음(회색 테두리) · 코드 낡음 / 바뀜(warn).
- **타임라인**: 20px 원 마디(성공 pass-wash ✓ · 실패 bad 면 ✕ · DB 확인 probe-wash ◇ · 안 돌림 well –) + 1px 세로선. 실패 단계 제목은 굵게, 오류는 bad-wash 면 + 모노.
- **이력 줄**: `시각 · 성공 n · 실패 n · 중단됨 · 결과서`. 실패가 0 이 아니면 빨간 굵게, 0 이면 평범한 글. 막대 없음.

## 키보드 · 포커스
- 모든 단추는 `:focus-visible` 에 probe 2px 링(오프셋 2). 다시 그려도 포커스가 있던 자리를 잃지 않게 `data-fk` 로 되돌린다(펼침 · 메뉴 · 체크 · 확인 상자).
- [수행 ▾] 메뉴: Enter 로 열면 첫 항목으로, ↑↓ 로 이동(비활성은 건너뜀), Esc 는 닫고 [수행 ▾] 로 돌아간다. 팝업 Esc 는 [환경] 으로 돌아간다.
