묶음이 없어졌습니다 — 시나리오가 유일한 단위이고, 화면(실행할 때 "확인:" 단계가 실행된 주소)과 요청(그 시나리오를 만든 채팅 요청)이 태그로 붙습니다. 시나리오 · 화면 그룹 · 요청 그룹을 골라 실행하고, 여러 개는 결과서를 "하나로 같이" 또는 "시나리오마다 따로" 낼 수 있습니다
실행 결과 · 비교 · 목록은 앱의 기록 저장소(host.db)에 남깁니다(호스트 API 2 를 지원하는 앱이 필요합니다). 이전 버전의 묶음 이력은 가져오지 않으며, 시나리오 파일을 직접 지우면 그 기록 · 스크린샷 · 결과서도 같이 정리됩니다
패널을 새 모양으로 다시 만들었습니다 — 전체(체크해서 실행 · 삭제) · 화면별 · 요청별 보기와 검색, 실행 중 진행 · 완료 알림, 시나리오 상세(단계 · 실패 스크린샷 · 최근 결과의 화면 가이드 · 결과서). 결과서 · 화면 가이드는 앱 안 미리보기로 열리고 [PDF 로 저장] 으로 PDF 파일로 저장할 수 있습니다(결과서 폴더에 PDF 가 남고 결과서를 지울 때 같이 지워집니다)
시나리오 · 결과서의 위치가 프로젝트의 .litecode/plugins/ui-test/ 아래로 정해졌습니다(시나리오 scenarios/ · 결과서 reports/<수행 id>/) — 설정의 "테스트 폴더" 칸은 없어졌고, 플러그인을 지우면 이 폴더가 (직접 쓴 시나리오까지) 함께 지워집니다. 이전 버전의 ui-tests/ 시나리오는 처음 한 번 새 위치로 복사해 가져오며(옛 폴더는 그대로 두니 필요 없으면 직접 지우세요) 결과서는 가져오지 않습니다. 결과서를 .gitignore 에 넣자는 제안은 .litecode/plugins/ui-test/reports/ 를 가리킵니다
